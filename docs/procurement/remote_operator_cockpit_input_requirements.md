# 挖掘机遥控座舱输入设备需求

## 1. 核心需求

我们需要一套挖掘机式遥控座舱输入设备，用来替代现有键盘和游戏手柄。

当前程序需要 **6 路可同时使用的双向比例输入轴**：

| 操作装置 | 数量 | 比例轴数量 | 用途 |
|---|---:|---:|---|
| 双轴摇杆 | 2 只 | 4 路 | 回转、动臂、斗杆、铲斗 |
| 履带行走踏板或推杆 | 左右各 1 只 | 2 路 | 左履带和右履带独立前进/后退 |
| **合计** |  | **6 路** |  |

这里的“一路比例轴”是一个从 `-100%` 到 `+100%` 连续变化的双向输入。例如左履带前进和后退合计为 1 路比例轴，不是两个按钮。

## 2. 最低和推荐配置

| 项目 | 最低要求 | 推荐配置 |
|---|---:|---:|
| 可用比例轴 | 6 路 | 8 路，额外 2 路留给后续属具 |
| 普通按钮 | 3 个 | 12～16 个 |
| 双轴摇杆 | 2 只 | 2 只工业霍尔摇杆 |
| 履带控制 | 2 路独立双向输入 | 左右独立、自动回中的脚踏或推杆 |
| 急停/使能 | 仿真阶段可选 | 各预留 1 个 |

普通按钮当前主要用于启动、暂停和复位；其余按钮可留给鸣笛、速度模式、灯光、摄像头和属具等功能。

## 3. 摇杆动作

建议采用常见挖掘机操作方式：

| 操作装置 | 方向 | 动作 |
|---|---|---|
| 左摇杆 | 左 / 右 | 上车左回转 / 右回转 |
| 左摇杆 | 前 / 后 | 斗杆伸出 / 收回 |
| 右摇杆 | 前 / 后 | 动臂下降 / 举升 |
| 右摇杆 | 左 / 右 | 铲斗收斗 / 翻斗 |

摇杆必须能够同时操作两个方向，例如可以在回转的同时伸出斗杆。所有主轴松手后应自动回到中位。

## 4. 履带操作

左右履带必须分别控制，优先使用左右脚踏或踏板/推杆一体机构，这样双手可以一直操作两只摇杆。

| 左履带 | 右履带 | 车辆动作 |
|---|---|---|
| 前进 | 前进 | 直行前进 |
| 后退 | 后退 | 直行后退 |
| 后退 | 前进 | 向左转 |
| 前进 | 后退 | 向右转 |

不建议使用四个前进/后退按钮代替比例踏板，也不建议把左右履带合并成一个方向盘或一个摇杆输出。

## 5. 接口要求

设备应提供以下任一种开放接口：

- **优先：CAN 接口**，供应商提供完整报文说明或 DBC 文件；
- **也可：USB HID**，Windows 能直接识别为游戏控制器。

接口至少满足：

- 6 路比例轴全部独立，并且可以同时输出；
- 数据刷新频率不低于 **50 Hz**，推荐 **100 Hz**；
- 有效分辨率不低于 **10 bit**，推荐 **12 bit**；
- 每个轴可以单独校准中位、最大值、最小值和方向；
- 松手后输出稳定回到 0，断开设备时程序能够识别失联；
- 供应商必须提供轴号、按钮号和通信格式，不能只说明“支持 CAN”。
