# 删除松土、履带压实与持续沉降

## Goal
将土壤模型收敛为“挖土—装土—倾倒—形成土坡”：挖掘扣除土量并装入斗内，倾倒直接生成具有休止角的稳定、可重新挖掘地形。移除松土状态、履带压实、自动沉降及相关队列和生命周期。

## Requirements
- 挖掘继续从地形扣除体积并记入斗内土量账本。
- 倾倒事务直接按休止角生成稳定坡形体积，落地后立即成为可重新挖掘的地形。
- 删除 `stable/mobile/compaction` 中仅用于松土、压实、沉降过程的运行时状态和更新机制；保留质量守恒所需的材料/体积账本及地形几何。
- 删除履带接触回执、压实 admission、压实提案/队列/事务和持续沉降调度。
- 历史调用安全退化为 no-op/明确拒绝，不得阻塞挖掘和倾倒。
- 清理相关配置、fixture、测试、调试状态和文档，并增加“落土立即稳定且可再挖”的回归覆盖。

## Acceptance Criteria
- [x] 倾倒完成后立即存在稳定休止角土坡，无飞行后松土、压实或持续沉降阶段。
- [x] 生成的土坡可被后续挖掘，挖出体积正确回到账本/斗内。
- [x] 运行时不再执行履带压实、松土流动或自动沉降，也不产生对应队列项、回执和事务。
- [x] 土量/质量守恒测试、挖掘、装斗、倾倒和再挖掘测试通过。
- [x] 相关压实/松土测试、fixture、配置、状态快照和文档已删除或改写为新的能力边界。
- [x] 人工测试验收完成（用户于 2026-09-09 确认）；按用户要求，代理未运行自动测试或 lint/type-check。

## Affected areas
`VoxelSoilMaterialField`、倾倒/落地事务、`VoxelExcavationAuthority`、履带接触回执、重新挖掘路径，以及压实/松土相关测试和文档。
