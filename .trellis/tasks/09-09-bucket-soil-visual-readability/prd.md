# 改善铲斗装土形态与斗内可见度

## 目标

用户于 2026-09-09 要求规划并创建任务：斗内土壤不应像悬浮立方体，而应从内底部逐渐增长、外观更自然；改善铲斗内部过黑。让操作者清楚观察土量、土面与斗腔的关系。

代码与五项聚焦自动测试完成。2026-09-09 用户反馈“做的很好”，认可当前成果并要求提交、推送和归档。

## 已确认背景

- 填料是程序化闭合网格，底面固定在 cavity 高度的 -0.48 倍，矩形边界直接连接到底面：`godot/client/scripts/soil_effects.gd:183-194,745-845`。它依据简化 proxy，未校准可见斗腔。
- voxel 模式的整个 fill profile 使用同一个 ratio：`godot/client/scripts/voxel_soil_material_field.gd:378-405`，土面起伏由表现层生成。
- 两机型 cavity/floor 定义不同：`godot/client/resources/models/sy135_soil_contract.json`、`sy205_soil_contract.json:36-40,97-103`。语义 wear plate 不等于可见内底面。
- 现有填料已有 Ground037 纹理、法线及局部坐标三平面映射：`godot/client/scripts/soil_visual_resources.gd:3-24`，不能仅靠添加纹理解决形状问题。
- balanced/high 的 SSAO 强度为 1.62、半径 1.25，曝光 0.96；low 关闭 SSAO：`godot/client/scripts/visual_environment.gd:74-84`。斗内过黑的具体成因尚未证实。

## 需求与验收

| ID | 需求 | 可观察验收标准 |
|---|---|---|
| R1 | 贴底增长 | 空斗无填料；约 5/25/50/75/100% 装载量逐步增加时，先形成贴底薄层，再扩大、堆高。正常观察角度下无悬浮空隙、独立矩形块或明显穿出底板/侧壁。 |
| R2 | 自然土堆 | 适度不规则起伏和可辨认的土壤细节，边缘贴合内腔；不能用整块等比缩放或直立矩形侧壁表达增长。纹理尺度合理，无明显拉伸、滑动或随机闪烁。 |
| R3 | 斗内可见度 | 空/半/满斗的迎光、背光姿态能辨认内壁、底板与土面；保留阴影深度及金属/泥土区别，无明显自发光、整斗发白或全场过曝。 |
| R4 | 兼容与生命周期 | SY135/SY205 分别适配；抬升、收斗、翻转时填料跟随；卸料随库存减少，清空、重置和换机型无残留；画质切换不丢失修正或累积补光。 |
| R5 | 权威与预算 | 同一输入下质量、库存、容量、挖掘/卸土交易、碰撞、载荷和关节行为保持。复用资源及有界更新机制，不引入逐粒刚体或每帧网格重建。 |

## 范围

斗内填料轮廓、增长映射、表面细节；与斗内可见度直接相关的材质、遮蔽和间接光诊断及受控调整；两机型与现有画质档位的针对性回归。

## 不在范围内

体素/稳定堆土算法、真实散体物理、容量标定、卸料粒子重做、湿度/附着系统、整车重建、关节/pivot 或碰撞代理修改、场景整体美术重做、日夜系统、后端和协议。

## 验证责任

**Agent automated**：几何底部/包络、装载增长单调性、确定性、跟随、清空/切换、资源复用及配置恢复的聚焦验证；只运行与最终改动有关的静态/导入和测试。

**Human manual**：Forward+ 下两机型连续装卸与代表性的空/半/满斗；balanced 为主，low/high 检查回退。自然度、阴影可读性和连续变化观感在用户反馈前均为 `pending human review`。
