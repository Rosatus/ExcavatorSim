# 落土时序与土壤视觉提升

## Goal

改善卸土过程中空中土流、地面堆积及土壤表面的连贯性与质感。用户反馈：地面先出现土堆，空中土壤随后才出现；空中颗粒像小方片；整体土壤视觉仍有提升空间。

## Background

- 当前 voxel deposit 先写入地面 SDF，再发布 accepted dump event；特效消费事件后才发射。代码顺序能解释时序问题，但具体画面延迟尚未测量。
- 空中主颗粒和大土块均使用 BoxMesh；桶内土与可挖 voxel 土层主要使用纯色粗糙材质。
- 前一任务已优化切削性能并将诊断设为默认关闭。本轮需保留这些收益。
- 用户于 2026-09-08 授权创建任务，随后明确要求按照任务进行开发。
- 调查依据见 `research/current-state.md`。

## Requirements

- R1：协调斗口释放、空中飞行和地面增长，避免明显的“地面先长出土堆，土流后出现”；覆盖低位和高位卸土。
- R2：消除空中土壤的规则方片观感，形成有大小变化、运动层次和连续性的落土表现。
- R3：提升可挖地面、堆积土和桶内土的表面质感及视觉一致性；材质风格和细节强度在设计阶段收敛。
- R4：保持单一土壤权威、土堆可重挖和碰撞派生关系；不得由视觉粒子独立增加或删除库存。
- R5：保持有界颗粒、土块与地形更新开销；不以持续增加粒子数量或提高体素精度作为默认改善手段。
- R6：修复用户后续反馈的卸土结束后仍出现空中土壤，以及 SY135 抬斗末段漏切表层悬土。无可表现余土时停止新释放；已参与切削的抬升需完成仍相交的尾部扫掠，不能让未接触的抬斗自行授权删土。

## Acceptance Criteria

- [ ] AC1 / R1：低位及高位连续卸土中，能读出从斗口到地面的运动过程，没有明显提前出现的完整土堆。
- [ ] AC2 / R1、R4：停止卸土或移动斗口后不继续从旧位置补生土；已释放的空中土正常收尾；重置后无残留事件。
- [ ] AC3 / R2：常用操作视角下，空中土不再以规则小方片为主要观感，连续卸土没有明显断流。
- [ ] AC4 / R3：桶内土、可挖区和新堆土具有协调的色调与可辨认表面细节，近看不只是纯色，远看无明显闪烁或纹理接缝。
- [ ] AC5 / R4：土堆仍可正常回挖；时序变更的库存、防重、拒绝及重置行为有针对性核验。
- [ ] AC6 / R5：同等场景与质量档比较性能，未引入明显切削或卸土卡顿；验收方法及性能预算在设计中明确。
- [ ] AC7 / R6：连续保持卸料姿态至桶空，最后落地后无持续新释放、残留大土块或旧快照补播；毫克级不可表现余量保留在账本中。
- [ ] AC8 / R6：真实体素测试中，先切入后抬升可移除尾部浅层残土；未接触抬升、外壳擦碰和完全离土仍拒绝切削。
- [ ] AC9 / R6：同一体素先被部分切削并记账后，后续扫掠仍可清除真实残土；不得因质量去重拒绝几何补切，也不得重复增加库存。补切必须正常更新地形版本和派生结果。

## Scope Boundaries

本轮围绕落土时序、空中土和可交互土壤表面，并纳入用户明确要求的抬斗末段漏切修复。暂不包含整场景美术重做、完整颗粒物理模拟、切削算法重写或体素分辨率升级。任何改变土壤权威生命周期的方案须在设计中明确其兼容性及代价。
