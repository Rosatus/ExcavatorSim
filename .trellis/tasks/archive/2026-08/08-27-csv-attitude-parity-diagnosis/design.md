# QML-Canonical CAN Pose Compatibility Design

## Objective

Make the existing GuideSystem/QML 3D guidance pipeline consume CAN generated by
Godot and the Python gateway and reconstruct the same guidance-frame pose. QML
is immutable for this task and is the sole oracle.

The comparison boundary is the QML frame it actually represents:

```text
slew center O / upper world attitude
  -> boom joint
  -> arm joint
  -> bucket joint
  -> bucket tip
```

Lower-chassis yaw remains a diagnostic input. The design does not add a second
yaw degree of freedom to QML.

## Authority And Repository Boundary

- Product changes live in `E:/projects/ExcavatorSim` only.
- `E:/projects/dev_arch2.0_36b5586c` is a read-only compatibility oracle.
- Runtime/build artifacts must not discover or import the sibling repository.
- Tests may receive an explicit reference-root path and compile/run an
  ephemeral harness against the unmodified reference sources.

## Data Flow

```text
Godot fixed-tick authoritative transforms
  chassis, upper, boom, arm, bucket
        |
        v
existing CTN1 telemetry packet (same tick/model/tick_ms)
        |
        v
QML compatibility mapper in Python gateway
  - rigid Godot -> QML Exca conversion
  - QML calibration inverse
  - joint twist -> Sensor2Ang inverse
  - GNSS A = O - Exca*GO
        |
        v
Sinan RTK + four Ruifen IMU CAN frames
        |
        +--> CSV -> reference can_replay (byte-transparent)
        |
        +--> PC001/SocketCAN (correct EFF flag)
        v
reference ProtocolParser -> GuidanceCore/lib_kin -> QML model
```

## Compatibility Profile

Add an explicit, versioned QML compatibility profile and loader rather than
overloading the legacy `--model` compensation table.

Suggested CLI:

```text
--compat-profile <profile.toml>
--qml-calibration <calibration.toml>
```

The profile records:

- schema/profile version, target `qml-guidance-3d`, model `sy135`;
- QML calibration SHA-256 and expected required keys;
- Godot-to-QML basis contract and gimbal policy;
- source frames (`upper` for body IMU, RTK heading and O);
- GO vector and vice-antenna mount contract;
- neutral relative transforms for upper/boom/arm/bucket;
- Godot joint-delta to QML joint-angle offset/sign mapping;
- bucket four-bar legal inversion interval;
- valid RTK status values and numeric tolerances.

When profile mode is requested, missing/malformed/non-finite data, model/hash
mismatch or incomplete calibration fails before binding UDP or opening sinks.
There is no fallback to legacy compensation. Without a profile, legacy CLI
behavior remains available until migration is explicitly completed.

The first deterministic profile binds the reference ground-truth calibration
fixture. A field release uses a separately captured deployment
`database/calibration.toml`; changing it changes the compatibility profile/hash
and requires rerunning parity fixtures.

## Root Attitude Mapping

Let `B_G` be the orthonormalized Godot upper world basis. Reuse the repository's
existing canonical mapping:

```text
C = [[1,0,0], [0,0,-1], [0,1,0]]
Q = Rz(-90 degrees)
Exca = Q * C * B_G * transpose(C)
```

Extract QML heading/roll/pitch from `Exca` using the exact decomposition in
`research/qml-canonical-contract.md`. Cardinal tests lock identity and positive/
negative Godot Y yaw. Near the roll gimbal singularity, profile mode either
uses previous-frame continuity or rejects the sample; it must never silently
jump branches.

Invert QML calibration before CAN encoding:

```text
body_parser_pitch = bodyPhiPitch - roll_error_IMU_Car
body_parser_roll  = bodyPhiRoll  + pitch_error_IMU_Car
A900_heading      = wrap360(bodyPhiHeading - yaw_error_IMU_Car)
```

Body IMU yaw is diagnostic only.

## GNSS Main Antenna And Status

For SY135, Godot `upper.origin` is the slew center O. Convert it to ENU with
`(east,north,up)=(x,-z,y)` and invert QML's position equation:

```text
GNSSA = O_target_ENU - Exca * GO
```

Encode GNSSA into A200/A300/A400. Do not send chassis origin as the main
antenna. A valid synthetic fix publishes the QML stable-orientation status
(`satelliteStatus=4`). Invalid/missing fixtures keep explicit invalid states.

Vice-antenna output is derived from a profile-bound vehicle-frame mount offset,
not the current undocumented one-metre fore/aft assumption. If deployment mount
geometry is unavailable, pose parity can proceed but release monitoring remains
blocked and must be reported as such.

Velocity is derived from successive synthetic GNSSA positions and telemetry
tick time, so slew-induced antenna motion is represented. It is not reconstructed
solely from average track speed and chassis forward.

## Working-Equipment Mapping

World Euler angles are not an authority. For every joint:

1. Compute `parent^-1 * child` from the same telemetry sample.
2. Compare it with the profile neutral relation.
3. Extract the signed local X twist and validate off-axis residual.
4. Map the delta through the profile's QML neutral/sign alignment to target
   `boomPhi/armPhi/bktPhi`.
5. Invert the active QML `Sensor2Ang` equations to parser-reported pitches.
6. Encode Ruifen slots `(-pitch, roll, yaw)`.

Boom and arm use closed-form inverse equations. Bucket uses a bracketed numeric
inverse of the exact QML four-bar function on the legal machine interval, then
must pass a forward-substitution check before emission. An unreachable or
multi-branch target rejects the sample with a diagnostic rather than emitting a
plausible wrong pose.

The neutral/sign alignment is characterized once against QML with neutral and
positive single-axis checkpoints and is then versioned in the profile. It is
not recalculated from ambiguous global Euler elevations at runtime.

## Transport Semantics

CSV output remains byte-compatible with reference `_replay`. Direct PC001 and
SocketCAN packing changes independently:

```text
standard: can_id & CAN_SFF_MASK
extended: CAN_EFF_FLAG | (can_id & CAN_EFF_MASK)
```

Tests cover representative RTK, Ruifen, slew and travel IDs. Channel handling,
relative replay timing and 2D slew parser behavior remain outside the pose
mapper; they are documented and do not alter the selected 3D oracle.

## Godot Changes

The production CTN1 packet already contains the five required transforms and
does not need a wire-version change. Godot changes are limited to:

- explicit settings/launch arguments for the selected compatibility profile and
  calibration resource when starting the packaged gateway;
- a same-tick pose checkpoint/test seam that records model/tick, five transforms,
  joint scalars and packet bytes for deterministic fixtures;
- tests proving the packet transforms match authoritative post-step truth and
  the neutral/+axis checkpoints used by the profile.

No second pose authority or QML-specific transform mutation is introduced into
Godot presentation.

## Verification Strategy

### Focused numeric contracts

- basis/cardinal cases: identity and Godot Y yaw `+/-90 degrees`;
- root cases: flat, chassis yaw, pure slew, slope plus slew;
- joint cases: neutral, each joint positive/negative, combined motion, limits;
- GNSS inverse: QML recomputes O from emitted A and Exca;
- bucket inverse: forward error within wire quantization;
- standard/extended raw CAN packing.

### End-to-end oracle

Generate checkpoints from Godot, run gateway encoding, CSV and reference replay
packing, then feed the exact frames into an ephemeral build of the unmodified
reference `ProtocolParser + GuidanceCore/lib_kin`. Compare:

- decoded heading/body/link fields;
- `bodyPhiHeading/Roll/Pitch`;
- `boomPhi/armPhi/bktPhi`;
- `slewingCenterENU`;
- bucket-tip ENU.

QML render transforms are checked in one live validation pass after numeric
closure; screenshots are supporting evidence, not the numeric oracle.

Internal targets are heading/body/joint error <= 0.03 degree after 0.01-degree
wire quantization, O error <= 0.02 m, and bucket-tip error <= 0.06 m or a tighter
profile-specific bound justified by the Godot/QML geometry delta. The reference
harness's existing broader tolerances cannot be the only assertions.

## Compatibility And Rollback

- Legacy no-profile mode stays unchanged until the QML profile passes all gates.
- Profile mode is fail-closed and can be disabled by removing its Godot launch
  setting, returning to legacy output without changing packet format.
- QML/reference source is not modified, so rollback is confined to Godot launch,
  Python mapping/profile and EFF packing changes.
- Packaged Windows and supported Linux gateways must bundle or locate their
  approved profile/calibration identically and expose their profile/hash in logs.

## Deferred Release Input

The reference tree does not contain the field deployment
`database/calibration.toml` or an explicit vice-antenna baseline. Automated
development uses the named ground-truth fixture. Field release remains blocked
until the actual calibration snapshot and vice-antenna mount are captured and
verified.
