# Optional map packs

Construction source assets live in the independent `godot/worldbuilding/construction` project, never inside the client asset tree. Scoped LFS rules cover its binary source files. Runtime data uses `res://maps/construction/`; the optional pack must not override host settings, addons or global script classes.

`MapCatalog` mounts `<executable-directory>/maps/construction.pck` with replacement disabled (editor: `godot/dist/maps`). Main-scene `main_map.gd` configures the chosen map before child initialization. Switching reloads the scene with a retained model ID and clears SceneTree menu pause; missing packs leave training usable. UI confirmation follows the same ownership policy as destructive model/reset actions.

Construction enables finite voxel excavation only when `WorkArea/ExcavationArea` opts in with status `voxel`. Configure an independent `VoxelZoneLayout` before the work zone initializes; the cutter and authority consume that same layout for sampling, clipping, native edit coordinates, deposit and collision queries. Never mutate the training static defaults. Hide training meshes and remove its walls/foundation on construction. Imported ground owns collisions outside the pit; the map ground creates control-map holes only when the host explicitly sets `excavation_enabled`, so standalone workbench previews and older hosts retain solid ground. `JoltChassisTrackRuntime` accepts readiness-gated voxel hits before checking the explicit static-map root and never falls back to the training heightfield on construction. Missing/older maps without an opted-in area remain driving-only. Static-map capacity is 32768 Jolt bodies because the source uses more than 22000.

Root-scene reloads retire scene nodes while autoloads survive. CAN must rebind presentation/chassis to the current scene and must not sample detached frames. Model/reset on the driving map must not resurrect training colliders. Product Sky3D stays the single runtime environment; the pack sky is for the independent workbench.

The optional `WorkArea/SpawnPoint` marker in the map supplies a world-space ground position and absolute chassis yaw. Main-map initialization resolves it after the map enters the tree, before the chassis initializes. Static-map spawning adds descriptor hull clearance/support sag above that ground elevation; it does not add the training rig's yaw a second time. Maps without the marker retain the origin default. Switching, resetting and changing models reuse the marker. `WorkArea/ExcavationArea` has only four non-colliding ground warning lines, with no posts/walls. The 18×28 m terrain has a 1.5 m protected perimeter to cover the coarse Terrain3D hole-grid seam. The starter soil profile is a `VoxelPitGenerator` surface parameterized by `WorkArea/ExcavationArea` meta `starter_pit_depth_m` (absent or 0 keeps a level surface at the area marker elevation, as on training). Construction sets 1.5 m: the approach half (local -Z, the spawn side) is a foundation pit reached by a gentle constant-grade full-width ramp; side walls and the midline dig face are cut-steep; the far half stays at grade as the remaining dig area. Below-grade soil is tinted as subsoil relative to the original grade datum, not the generated profile. Reset regenerates the same starter profile, retires previous voxel readiness and clears soil accounting. Status reads after scene detachment return an unavailable identity transform instead of querying a retired Node3D's global transform.

Focused checks: `map_switch_test.gd` with `-- --without-map-packs`, followed by `construction_pack_test.gd` after building the real pack. Source dependency audit includes binary resources; text-only path replacement misses materials inside `.res` meshes. Build uses the same pinned engine/import format as the host. Human review owns visual appearance and driving feel.

Texture budgets must cover GLB-extracted images as well as copied source textures. The build normalizes sidecars before/after import using `tools/prepare_construction_textures.py`; new textures default to 1024, decals are capped at 1024, and other explicit limits are retained. Preserve source pixels. Several individually valid 8K decal textures can overflow the shared renderer atlas; headless loading does not exercise this failure. For this regression, the real-pack rendered check must report positive draw calls and no rendering errors; first-frame timing is not a cold-start or editor-debugger guarantee.


Automatic map excavation must pass the operator/Jolt query path: BucketProxySweeper validates the explicit map root and its static (0,0) collision identity, while ExcavationWorld compares tick/epoch/revision to the current chassis snapshot. Never compare a map query to the disabled training TerrainCollider/TerrainState. Test via actual equipment commands after reset, not only direct soil-authority calls.

Terrain3D control holes erase adjacent triangles and VoxelTerrain bounds round to mesh blocks. Visual soil/native-ground seams therefore clip fragments against the same semantic XZ rectangle; collision control holes remain separate native data. The finite soil generator includes a hidden immutable 1 m collision apron outside the editable domain to bridge native heightmap-hole expansion. The four warning lines retain the semantic perimeter. Validate rays immediately inside/outside all four edges plus real rendered shader uniforms and screenshots; control-map point tests alone miss this seam regression.


Track support accepts the immutable 1 m apron outside the semantic soil rectangle
only when the hit point's own canonical collision block is ready. Initial surface
readiness registers the apron blocks as well as the interior. This does not
expand `owns_world_xz`, editable soil bounds or excavation authorization.
