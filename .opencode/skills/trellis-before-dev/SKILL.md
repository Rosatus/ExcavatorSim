# Before editing
Understand goal, acceptance, affected architecture and actual code. For tracked work use requirements/current checkpoint; design and manifests are optional.
Read relevant spec indexes and applicable contracts once. Discover packages only if locations are unknown. Thinking guides are for concrete cross-layer/reuse questions, not mandatory loading.
Do not reread unchanged material already in context. Search consumers when changing shared contracts, not the whole repository for every local value. The editor must inspect the actual code.
Choose validation using `.trellis/validation.md`. No task creation, full workflow loading or additional approval is required by this skill.
