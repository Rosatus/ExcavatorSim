# 概念架构设计

## 页面结构

1. 标题、读者说明和事实截止日期。
2. 一句话模型：“输入意图 → Python 安全运动计算 → Godot 拟真呈现 → 显示反馈”。
3. 状态图例。
4. Mermaid 主图。
5. HTML 对照主图。
6. “看图即可理解”三行说明和当前/目标硬件对照表。
7. 下一步阅读链接：工程详细架构与专项契约。

## 图语义

当前实线链路：操作人员 → 键盘/通用手柄 → Godot 客户端 → Python 运动/安全核心 → Godot 拟真场景 → 桌面显示器。

未来虚线链路：座舱手柄/踏板/按钮面板 → CAN-to-USB/设备适配层 → 输入适配边界；中控/触屏 ← 状态/诊断适配层。未来链路不改变当前 Python 运动 authority 与 Godot 场景职责，且不声称协议已定。

legacy 兼容层仅以侧边灰色节点出现，标明 Python legacy terrain/recording/replay 可用于兼容回归，不是当前 Godot-first 主路径。
